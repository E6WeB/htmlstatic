## Overview

Polar is an open-source Merchant of Record built specifically for developers, indie hackers, and open-source maintainers. It handles global sales tax, VAT, checkout links, digital file delivery, software license keys, and usage-based or recurring SaaS billing.

Static websites can link directly to Polar's hosted checkout URLs or embed Polar checkout modals with zero backend code.

---

## Key Highlights & Features

1. **Developer-First Merchant of Record**: Handles international VAT/sales tax compliance and invoicing automatically.
2. **Hosted Checkout Links & Embeds**: Sell products or subscriptions from any static HTML button.
3. **Automated Benefits**: Built-in delivery for file downloads, software license keys, GitHub repo access, and Discord roles.
4. **Open Source**: Transparent codebase with modern APIs and webhooks.

---

## How It Works with Static Websites

Link any button on your static site to a Polar Checkout Link or embed script:

```html
<a href="https://polar.sh/YOUR_ORG/products/YOUR_PRODUCT_ID"
   target="_blank"
   rel="noopener noreferrer"
   class="polar-buy-button">
  Get Access
</a>
```

---

## When to Use It

1. Developers selling templates, CLI tools, SaaS plans, or private GitHub repo access from a static site.
2. Open-source creators wanting built-in license key generation and global tax handling.
3. Projects seeking an open-source alternative to Lemon Squeezy or Gumroad.

---

## Pricing & Transaction Fees

- **Starter Plan**: $0/month — **5% + $0.50** per transaction
- **Pro Plan**: $20/month — lowers transaction fee to **3.8% + $0.40** per transaction
- **Growth Plan**: $100/month — **3.6% + $0.35** per transaction
- **Scale Plan**: $400/month — **3.4% + $0.30** per transaction
- **Tax Compliance**: Global VAT and sales tax handling is included in the Merchant of Record fee (additional cross-border/payout fees may apply)
