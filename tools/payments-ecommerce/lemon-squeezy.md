## Overview

Lemon Squeezy is an all-in-one platform for selling digital products, software licenses, ebooks, and subscriptions. Acting as a Merchant of Record (MoR), Lemon Squeezy handles global sales tax, VAT calculation, and remittance automatically.

For static site owners, Lemon Squeezy provides both hosted checkout URLs and an embeddable overlay checkout script that keeps customers on your page.

---

## Key Highlights & Features

1. **Merchant of Record**: Handles global tax, VAT, and compliance on your behalf.
2. **Overlay Checkout**: Beautiful modal checkout that opens directly on your static site.
3. **License Key Management**: Built-in generation and validation for software licenses.
4. **Affiliate Program**: Built-in system to launch and manage an affiliate program.

---

## How It Works with Static Websites

Add Lemon.js to your static HTML page for an overlay checkout modal:

```html
<!-- Load Lemon Squeezy script -->
<script src="https://assets.lemonsqueezy.com/lemon.js" defer></script>

<!-- Checkout button -->
<a href="https://yourstore.lemonsqueezy.com/buy/PRODUCT_ID?embed=1"
   class="lemonsqueezy-button">
  Purchase License
</a>
```

## When to Use It

1. Selling digital downloads, software licenses, presets, and courses.
2. Sellers who want someone else to handle worldwide VAT and sales tax compliance.
3. Static product landing pages needing a smooth popup checkout experience.

## Pricing & Transaction Fees

- **Monthly Fee**: $0/month (pay-as-you-go)
- **Base Transaction Fee**: 5% + $0.50 per transaction
- **Additional Surcharges**: +1.5% for international cards, +1.5% for PayPal payments, +0.5% for subscription renewals
- **Email Marketing**: Free up to 500 subscribers, with paid tiers for larger lists
