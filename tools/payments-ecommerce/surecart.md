## Overview

SureCart is a headless e-commerce platform whose checkout, order management, subscription billing, and customer portal run on SureCart's cloud infrastructure. While widely used with WordPress, SureCart generates standalone **hosted checkout pages** and direct **Buy Now links** that you can drop onto any static HTML website.

You can connect Stripe, PayPal, or other supported gateways to sell one-time products, payment plans, or recurring subscriptions with order bumps and digital file delivery.

---

## Key Highlights & Features

1. **Standalone Hosted Checkout Links**: Link any static HTML button directly to a fast, hosted SureCart checkout page.
2. **Headless Cloud Architecture**: Offloads carts, orders, customer portals, and tax logic to SureCart's servers.
3. **Subscriptions & Payment Plans**: Built-in support for recurring billing, free trials, installments, and pay-what-you-want pricing.
4. **Order Bumps & Upsells**: Conversion-focused checkout features included even on the free Launch plan.

---

## How It Works with Static Websites

Create a product in SureCart and attach its Instant Checkout link to a button on your static site:

```html
<a href="https://checkout.surecart.com/YOUR_CHECKOUT_ID"
   target="_blank"
   rel="noopener noreferrer"
   class="surecart-buy-button">
  Buy Now
</a>
```

---

## When to Use It

1. Static landing pages that need hosted checkout links with subscriptions, installments, or order bumps.
2. Creators who want to start for $0/month and later upgrade to an annual or lifetime plan to remove platform fees.
3. Hybrid sites using SureCart for both static landing pages and WordPress-based storefronts.

---

## Pricing & Transaction Fees

- **Launch Plan (Free)**: $0/month — includes core checkout, digital delivery, and subscriptions with a **2.9% platform transaction fee**
- **Pro Plan (Annual)**: ~$199/year (single store) — removes SureCart's platform transaction fee
- **Pro Plan (Lifetime)**: ~$699 one-time (single store) — removes SureCart's platform transaction fee
- **Payment Processor Fees**: Standard Stripe or PayPal processing fees (e.g., 2.9% + $0.30) apply on all plans
