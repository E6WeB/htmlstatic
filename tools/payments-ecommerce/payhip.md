## Overview

Payhip is an e-commerce platform that enables creators to sell digital downloads, software, ebooks, memberships, and physical products. It integrates with PayPal and Stripe and features built-in EU VAT handling.

Payhip offers a lightweight embed script allowing customers to complete purchases without ever leaving your static website.

---

## Key Highlights & Features

1. **Direct File Delivery**: Automatically delivers secure download links after purchase.
2. **In-Page Checkout Overlay**: Customers complete checkout inside an on-page modal.
3. **EU VAT Management**: Calculates and reports European VAT automatically.
4. **Customer Accounts**: Member portals for recurring subscriptions and course materials.

---

## How It Works with Static Websites

Embed Payhip checkout onto your static site:

```html
<!-- Payhip Embed Script -->
<script type="text/javascript" src="https://payhip.com/payhip.js"></script>

<!-- Buy Button -->
<a href="https://payhip.com/b/PRODUCT_KEY"
   class="payhip-buy-button"
   data-theme="blue">
  Buy Now
</a>
```

## When to Use It

1. Selling ebooks, design assets, icon packs, and templates directly from a portfolio.
2. Websites needing instant secure file delivery to buyers.
3. Creators seeking a simple checkout overlay with low transaction fees.

---

## Pricing & Transaction Fees

- **Free Forever Plan**: $0/month + **5% transaction fee** per sale
- **Plus Plan**: $29/month + **2% transaction fee** per sale
- **Pro Plan**: $99/month + **0% Payhip transaction fee**
- **Payment Processor Fees**: Standard Stripe or PayPal processing fees still apply on all plans
