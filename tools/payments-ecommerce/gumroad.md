## Overview

Gumroad is a popular creator e-commerce platform and Merchant of Record for selling ebooks, templates, software, courses, and recurring memberships. Because Gumroad handles file hosting, license keys, and global sales tax/VAT, static site owners can sell products without any backend infrastructure.

Adding Gumroad's lightweight `gumroad.js` script turns any standard HTML link into an on-page overlay checkout modal.

---

## Key Highlights & Features

1. **Overlay & Embed Checkout**: Include `gumroad.js` to open a clean checkout modal directly over your static page.
2. **Merchant of Record**: Automatically collects and remits global sales tax and VAT.
3. **Instant Digital Delivery**: Hosts your files and delivers secure download links or software license keys after purchase.
4. **No Monthly Fee**: Start selling with $0/month upfront and pay only when you make a sale.

---

## How It Works with Static Websites

Include the Gumroad script and link to your product URL:

```html
<!-- Load Gumroad overlay script -->
<script src="https://gumroad.com/js/gumroad.js" defer></script>

<!-- Buy button -->
<a class="gumroad-button" href="https://yourstore.gumroad.com/l/YOUR_PRODUCT">
  Buy Now
</a>
```

---

## When to Use It

1. Quickly selling templates, ebooks, presets, or Notion/code kits from a static landing page.
2. Creators who want built-in file delivery, license keys, and global VAT handling with zero setup.
3. Projects that prefer $0 monthly fixed costs over a monthly SaaS subscription.

---

## Pricing & Transaction Fees

- **Monthly Fee**: $0/month (no monthly subscription)
- **Direct Sales Fee**: **10% + $0.50** per transaction (when buyers purchase via your direct links or embedded buttons)
- **Discover Marketplace Fee**: **30% flat** per transaction (for sales originating from Gumroad Discover)
- **Payment Processing**: Standard card/PayPal processing fees apply depending on transaction setup
