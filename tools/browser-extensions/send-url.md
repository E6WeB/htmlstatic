# Send URL

> Chrome browser extension that implements a one-click button to quickly email the active webpage title and URL via mailto protocol.

- **Official Website**: <a href="https://chromewebstore.google.com/detail/send-url/fmanefafgomooabofffoidipbfdbjilh" target="_blank" rel="noopener noreferrer">Chrome Web Store</a>
- **Category**: [Browser Extensions](../../README.md#browser-extensions)
- **Type**: Browser Extension
- **Pricing / License**: Free

---

## Overview

Send URL is a lightweight Chrome browser extension designed for sharing webpage links and titles. It adds an accessible action button directly next to the browser address bar that automatically prepares an email draft with the current page title as the email subject and the URL in the message body.

Because it relies on the standard `mailto:` protocol, it works seamlessly with whichever email client or webmail service is configured on your system (such as Gmail, Apple Mail, Outlook, or Thunderbird). For web developers and static site creators, it offers a frictionless way to share links, conduct QA reviews, and send test URLs to clients or teammates directly from the browser without tedious copy-pasting.

---

## Key Highlights & Features

- **One-Click Sharing**: Adds a convenient action button next to the address bar for instantaneous sharing.
- **Native Mailto Integration**: Uses standard system `mailto:` handling with zero third-party tracking or data harvesting.
- **Automatic Title & URL Extraction**: Automatically fills the email subject with the webpage title and the body with the link.
- **Webmail & Desktop Client Support**: Works with Gmail, Outlook, Apple Mail, Thunderbird, or any system default client.
- **Lightweight & Private**: Zero background dependencies, minimal permissions, and zero tracking.

## How It Works with Static Websites

Developers and content curators building static websites can instantly share staging links, GitHub Pages previews, or specific tool pages with teammates and clients:

Click the Send URL button while browsing any static web project to immediately generate a draft:

```text
Subject: StaticStack - Tool Directory
Body: https://staticstack.app/tools/development-tools/antigravity-ide
```

## When to Use It

- Sharing live or preview URLs from static websites with teammates, clients, or testers.
- Bookmarking or forwarding web tools, documentation guides, and articles via email.
- Streamlining QA feedback workflows for static web frontends.
