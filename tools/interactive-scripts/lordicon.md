## Overview

Lordicon offers thousands of carefully crafted animated icons built on Lottie. Its lightweight `<lord-icon>` custom HTML element lets static site developers trigger icon animations on hover, click, scroll, or loop without writing custom animation code.

---

## Key Highlights & Features

1. **Interactive Triggers**: Animate icons on `hover`, `click`, `morph`, `loop`, or `in` viewport.
2. **Live Styling**: Customize primary/secondary colors and stroke weight directly via HTML attributes.
3. **Self-Hostable JSON**: Download JSON icon files to serve locally from your static assets folder.
4. **Free Starter Pack**: Includes hundreds of free animated icons for personal and commercial sites.

---

## How It Works with Static Websites

```html
<script src="https://cdn.lordicon.com/lordicon.js"></script>
<lord-icon src="/assets/icons/rocket.json" trigger="hover" style="width:48px;height:48px"></lord-icon>
```
