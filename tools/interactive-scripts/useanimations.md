## Overview

useAnimations is a focused library of free Lottie micro-animations for everyday UI controls—menu toggles, checkboxes, bookmarks, loading spinners, social icons, and alert indicators. Each icon is lightweight and ready to embed in static HTML or vanilla JS.

---

## Key Highlights & Features

1. **100% Free to Download**: Grab clean Lottie JSON files without account friction.
2. **Purpose-Built Micro-Interactions**: Designed specifically for buttons, nav toggles, and status states.
3. **Tiny JSON Payloads**: Minimal vector paths keep pages fast.
4. **Easy Vanilla JS Integration**: Works seamlessly with `lottie-web` or `dotlottie-player`.
