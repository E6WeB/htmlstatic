## Overview

Lottielab lets you design and animate vector graphics directly in the browser without After Effects. Import SVGs or Figma designs, add keyframe motion and interactive states, and export ultra-lightweight Lottie JSON or `.lottie` files for static websites.

---

## Key Highlights & Features

1. **No After Effects Required**: Full keyframe timeline editor in the browser.
2. **Figma & SVG Import**: Bring existing static brand SVGs to life quickly.
3. **Interactive State Machines**: Trigger hover, click, and toggle transitions cleanly.
4. **Free Tier**: Create and export animations for personal and static web projects.
