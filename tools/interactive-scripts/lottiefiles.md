## Overview

LottieFiles is the largest repository and tooling ecosystem for Lottie (`.json` / `.lottie`) vector animations. You can browse thousands of free community animations, tweak colors directly in the browser, and embed them in static HTML using a lightweight `<lottie-player>` or `dotlottie-player` web component.

---

## Key Highlights & Features

1. **Tiny Vector Payloads**: JSON/dotLottie animations scale crisply at any resolution at a fraction of GIF/MP4 file sizes.
2. **Drop-In Web Component**: Embed animations in plain HTML with a single `<script>` and custom element.
3. **In-Browser Color Editor**: Match animation palettes to your site's CSS theme before exporting.
4. **dotLottie Support**: Ultra-compressed `.lottie` archives for faster static page loads.

---

## How It Works with Static Websites

```html
<script src="https://unpkg.com/@dotlottie/player-component@latest/dist/dotlottie-player.mjs" type="module"></script>
<dotlottie-player src="/assets/animation.lottie" background="transparent" speed="1" style="width: 240px; height: 240px;" loop autoplay></dotlottie-player>
```
