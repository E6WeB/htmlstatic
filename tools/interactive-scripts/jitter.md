## Overview

Jitter is a fast, Figma-friendly motion design tool that runs in your browser. Designers and static web developers use it to animate UI mockups, hero graphics, and micro-interactions, then export to Lottie JSON, WebM, MP4, or GIF.

---

## Key Highlights & Features

1. **Preset Motion Actions**: Animate text, cards, and UI frames in seconds without complex curves.
2. **Figma Plugin**: Import designs directly from Figma and animate layers cleanly.
3. **Lottie & WebM Export**: Output web-optimized motion assets for static landing pages.
4. **Free Starter Plan**: Create and export animations directly from the browser.
