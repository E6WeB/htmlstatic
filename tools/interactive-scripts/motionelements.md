## Overview

MotionElements is a stock media marketplace featuring thousands of Lottie JSON animations alongside video loops, icons, and audio assets. Static site creators can search for lightweight Lottie graphics or free weekly elements to enhance landing pages.

---

## Key Highlights & Features

1. **Dedicated Lottie Catalog**: Searchable JSON animations ready for web players.
2. **Weekly Free Elements**: Free downloadable assets available with a free account.
3. **Multiple Formats**: Download Lottie JSON, GIF, or web-ready video loops.
4. **Commercial Licensing**: Clear royalty-free licensing for client and agency static sites.
