## Overview

Icons8 Animated Icons provides hundreds of crisp micro-interaction icons designed for navigation bars, buttons, loading states, and feature grids. Every icon can be exported as lightweight Lottie JSON to play natively on static HTML pages.

---

## Key Highlights & Features

1. **Lottie JSON Export**: Crisp vector motion at tiny file sizes.
2. **Consistent Design Systems**: Matches popular UI icon styles across your site.
3. **Free Tier Available**: Free animated icons with attribution or paid commercial licensing.
4. **Zero-Backend Embedding**: Serve exported JSON directly from your static `/assets/` directory.
