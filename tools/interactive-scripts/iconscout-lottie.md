## Overview

IconScout provides a large searchable collection of Lottie animations, animated icons, and 3D/vector motion graphics ready for web embedding. Assets can be previewed, recolored in-browser, and downloaded as `.json` or `.lottie` files for static websites.

---

## Key Highlights & Features

1. **Color Palette Customization**: Recolor multi-layer animations before downloading.
2. **Multiple Export Formats**: Download as Lottie JSON, dotLottie, SVG, or GIF.
3. **Consistent Packs**: Matching icon and illustration sets for cohesive landing pages.
4. **Free & Pro Tiers**: Includes free community Lottie assets alongside commercial packs.
