## Overview

IconKing provides clean, consistent animated icon packs in Lottie JSON and vector formats. Ideal for static SaaS landing pages, feature sections, and dashboards that need crisp motion without heavy video files.

---

## Key Highlights & Features

1. **Ready-to-Use Lottie JSON**: Drop straight into any static web page player.
2. **Clean Vector Geometry**: Sharp rendering on Retina and mobile displays.
3. **Lightweight Assets**: Keeps Core Web Vitals fast compared to animated GIFs.
4. **Free & Commercial Packs**: Includes free sample animations alongside full sets.
