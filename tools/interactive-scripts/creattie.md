## Overview

Creattie offers professionally designed animated illustrations and icons built on Lottie. You can customize stroke width, colors, animation speed, and interaction triggers right in the browser before downloading clean embed code or JSON files for static sites.

---

## Key Highlights & Features

1. **Interactive Embed Builder**: Configure hover, click, or loop behavior before exporting.
2. **Consistent Illustration Packs**: Hero illustrations and matching UI icons in the same art style.
3. **Color & Speed Controls**: Fine-tune palette and playback directly on the site.
4. **Free & Premium Assets**: Includes free starter animations for testing and side projects.
