## Overview

ThemeVault provides a curated collection of free, modern website templates spanning classic HTML5/CSS3, Bootstrap, and modern static site frameworks like Astro and Next.js. Designed with clean typography and mobile-first layouts, ThemeVault templates are tailored for SaaS products, creative studios, portfolios, and corporate websites.

---

## Key Highlights & Features

1. **Modern Stack Variety**: Offers both traditional static HTML/CSS/Bootstrap bundles and modern Astro/Next.js starter templates.
2. **Mobile-First & Responsive**: Tested across modern viewports for clean grid alignment and fast mobile rendering.
3. **Lightweight Assets**: Minimal external dependencies for strong Google Lighthouse and Core Web Vitals scores.
4. **Free for Static Deployment**: Ready to customize and push straight to GitHub Pages, Vercel, or Cloudflare Pages.

## How It Works with Static Websites

Choose an HTML5 or Astro template from ThemeVault, download the source archive, edit your content locally, and deploy to any CDN:

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Portfolio — ThemeVault</title>
  <link rel="stylesheet" href="css/style.css">
</head>
<body>
  <section class="hero">
    <h1>Minimal Static Portfolio</h1>
  </section>
</body>
</html>
```
