## Overview

TemplateMo offers over 600 free HTML5 and CSS website templates built with responsive layouts and modern Bootstrap grids. Every template on TemplateMo is completely free to download and use for personal, educational, or commercial static websites.

Templates cover a wide variety of styles—including SaaS landing pages, digital agencies, photography portfolios, e-commerce storefronts, restaurants, and corporate websites—with live interactive demos for every design.

## How It Works with Static Websites

Download a TemplateMo `.zip` archive, open the files in your editor, and customize the HTML sections:

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Agency Static Site</title>
  <link href="css/bootstrap.min.css" rel="stylesheet">
  <link href="css/templatemo-style.css" rel="stylesheet">
</head>
<body>
  <main>
    <section class="hero-section">
      <h1>Ready-to-Edit Static HTML</h1>
    </section>
  </main>
</body>
</html>
```
