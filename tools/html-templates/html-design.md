## How It Works with Static Websites

Download a template package from HTML Design, swap in your text and WebP images, connect a serverless form like [Formspree](/tools/contact-forms/formspree) or [Basin](/tools/contact-forms/basin), and host it for free on any static edge network:

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Business Site — HTML Design</title>
  <link rel="stylesheet" href="css/bootstrap.min.css">
  <link rel="stylesheet" href="css/style.css">
</head>
<body>
  <header class="header_section">
    <h1>Modern Static Business</h1>
  </header>
  <script src="js/custom.js"></script>
</body>
</html>
```
