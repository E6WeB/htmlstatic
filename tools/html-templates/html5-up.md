## Overview

HTML5 UP (created by AJ / @ajlkn, also behind Carrd and Pixelarity) is one of the most respected collections of modern, handcrafted HTML5 and CSS3 website templates. Every design is original, mobile-first, and built with clean semantic HTML and Sass/CSS.

All templates on HTML5 UP are 100% free to download and use for both personal and commercial static websites under the Creative Commons Attribution 3.0 license.

---

## Key Highlights & Features

1. **Handcrafted Original Designs**: Every template (like *Dimension*, *Massively*, *Stellar*, *Forty*, and *Editorial*) features bespoke typography, smooth transitions, and polished layouts.
2. **100% Responsive & Mobile-First**: Built on clean Flexbox and CSS grid primitives that adapt seamlessly across phones, tablets, and desktops.
3. **Pure Static HTML, CSS & Sass**: Includes compiled CSS alongside well-organized `.scss` source files for effortless customization.
4. **Free under Creative Commons**: Free for personal and commercial projects with simple footer attribution.

## How It Works with Static Websites

Download a template from HTML5 UP, unzip it into your project repository, and deploy directly to any static host (GitHub Pages, Cloudflare Pages, Wasmer, or Netlify):

```html
<!DOCTYPE HTML>
<!-- Template by HTML5 UP (html5up.net) | CC BY 3.0 -->
<html>
  <head>
    <title>Portfolio — HTML5 UP</title>
    <meta charset="utf-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1, user-scalable=no" />
    <link rel="stylesheet" href="assets/css/main.css" />
  </head>
  <body class="is-preload">
    <div id="wrapper">
      <header id="header">
        <h1>Clean Static HTML5</h1>
        <p>Ready for instant deployment on any CDN</p>
      </header>
    </div>
    <script src="assets/js/main.js"></script>
  </body>
</html>
```
