## How It Works with Static Websites

Browse Colorlib's HTML & CSS template catalog, download the template ZIP, customize the HTML files in [Visual Studio Code](/tools/development-tools/visual-studio-code), and deploy directly to any static host like [Wasmer.io](/tools/hosting-deployment/wasmer) or [Cloudflare Pages](/tools/hosting-deployment/cloudflare-pages):

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Agency Site — Colorlib Template</title>
  <link rel="stylesheet" href="css/bootstrap.min.css">
  <link rel="stylesheet" href="css/style.css">
</head>
<body>
  <main>
    <h1>Static Website Ready</h1>
  </main>
</body>
</html>
```
