## Overview

Utterances is a lightweight, open-source comment widget that uses GitHub issues to store and display comments. When a page is visited, Utterances uses the GitHub search API to find the issue associated with the article or creates one automatically when the first comment is submitted.

It has zero tracking, zero ads, no bloat, and pairs naturally with static blogs.

---

## Key Highlights & Features

1. **Ultra Lightweight**: Minimal JavaScript footprint with zero tracking.
2. **GitHub Issues Backend**: Read and reply to comments directly inside GitHub Issues.
3. **Markdown Support**: Full GitHub Flavored Markdown support in comments.
4. **Clean Themes**: Seamlessly blends with light and dark GitHub styles.

---

## How It Works with Static Websites

Embed Utterances into your HTML template:

```html
<script src="https://utteranc.es/client.js"
        repo="your-username/your-repo-name"
        issue-term="pathname"
        theme="github-light"
        crossorigin="anonymous"
        async>
</script>
```

## When to Use It

1. Minimalist developer blogs and portfolios.
2. Static sites built with Hugo, Eleventy, Jekyll, or Astro.
3. Creators who want simple, bloat-free commenting powered by GitHub.
