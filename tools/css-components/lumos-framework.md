## Overview

Lumos Framework is a free, open-source component and styling framework built specifically for Astro. Created by Timothy Ricks, it combines modern CSS design tokens, fluid typography and spacing, container queries, and reusable accessible components into a structured system for static and content-driven websites.

Rather than shipping heavy client-side JavaScript or opaque abstractions, Lumos embraces semantic HTML, a predictable CSS cascade, and copy-pasteable Astro components that render zero client-side JavaScript by default.

---

## Key Highlights & Features

1. **Astro-Native Components**: Reusable UI components tailored for Astro's zero-JS-by-default architecture.
2. **Design Tokens & Fluid Scaling**: Centralized CSS variables with `rem`-based fluid typography and spacing systems.
3. **Container Query Layouts**: Supports breakpointless, component-driven responsive layouts using modern CSS container queries.
4. **Smart Component Conventions**: Built-in conditional rendering escape hatches and self-cleaning empty states when CMS fields are omitted.
5. **Accessibility-First & MIT Licensed**: Semantic HTML patterns with no accounts, paywalls, or per-seat licensing.

---

## When to Use It

1. Astro static sites that need a scalable, maintainable design system without Tailwind or heavy UI libraries.
2. Content-driven and CMS-backed static sites where clean empty-state handling and consistent spacing matter.
3. Developers and Webflow/Lumos practitioners adopting Astro while keeping familiar token and layout conventions.
