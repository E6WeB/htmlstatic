## Overview

Cursor is an AI-first code editor built as an enhanced fork of Visual Studio Code. It provides natural language editing, multi-line tab completions that predict your next edits, and a powerful multi-file editing canvas called Composer.

Because it is built on VS Code, Cursor supports your existing extensions, themes, and keybindings out of the box while embedding state-of-the-art AI assistance directly into every keystroke.

---

## Key Highlights & Features

- **Composer (`Ctrl/Cmd+I`)**: Multi-file agent that generates, creates, and edits multiple HTML, CSS, and JavaScript files in parallel.
- **Next-Action Tab Completion**: Predicts multi-line code additions, function completions, and CSS rules as you type.
- **Codebase Indexing**: Indexes your entire repository locally so AI chat answers reflect your exact HTML markup and styles.
- **VS Code Extension Compatibility**: Full access to the VS Code extension marketplace, settings sync, and themes.

---

## How It Works with Static Websites

1. Open a static website folder in Cursor.
2. Press `Cmd+K` (or `Ctrl+K`) inside any HTML or CSS file to make targeted inline modifications.
3. Open **Composer** (`Cmd+I`) to build an entire new feature across multiple files:
   ```text
   "Add a sticky navbar with smooth scrolling to sections and a mobile hamburger menu toggle"
   ```
4. Review the visual diffs across `index.html`, `style.css`, and `main.js`, then click **Accept All**.
