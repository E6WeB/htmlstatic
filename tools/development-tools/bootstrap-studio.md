## Overview

Bootstrap Studio is a powerful desktop application tailored for web designers and developers to build responsive websites visually using the Bootstrap framework. Available for Windows, macOS, and Linux, it brings together drag-and-drop visual design tools with full-featured code editing (HTML, CSS, SASS, and JavaScript).

Unlike online website builders or proprietary platforms, Bootstrap Studio runs entirely offline on your computer and requires no ongoing monthly subscriptions. It generates clean, semantic HTML and standard CSS/JS that feels hand-written by a professional developer, making it easy to export and host on any static hosting provider, CDN, or server.

---

## Key Highlights & Features

- **Visual Drag-and-Drop Canvas**: Assemble responsive web pages with a vast library of built-in Bootstrap components (navbars, grids, cards, modals, carousels, and forms).
- **Clean Code Export**: Generates production-ready, clean, and semantic static HTML, CSS, and JavaScript with zero proprietary scripts or vendor lock-in.
- **Advanced Code Editing**: Built-in VS Code-style editor for CSS, SASS, JavaScript, and custom HTML with syntax highlighting, auto-completion, and real-time preview sync.
- **Real-Time Multi-Device Preview**: Connect phones, tablets, or other desktop browsers over local Wi-Fi to test responsive layouts and interactions live as you edit.
- **Smart Forms Integration**: Built-in form backend capability that routes form submissions directly to your email without writing backend code.
- **One-Click Publishing & Hosting**: Includes 5 free hosting slots on Bootstrap Studio Sites with custom domain support and SSL, or direct export via SFTP / ZIP download.
- **Offline & One-Time Purchase**: A native desktop application that you own forever with no mandatory monthly recurring fees.

## How It Works with Static Websites

### 1. Visual Drag-and-Drop Assembly
Drag and drop Bootstrap components into the visual canvas or DOM component tree. Customize properties, typography, layouts, and responsive breakpoints using visual controls.

### 2. Code Editing & Custom Logic
Seamlessly switch to code view to write custom CSS or SASS rules, link external JavaScript libraries, or embed custom HTML snippets.

### 3. Static Site Export
Export your completed design into a clean directory of static assets ready for deployment:

```bash
# Exported folder structure
my-website/
├── index.html
├── about.html
├── contact.html
├── assets/
│   ├── bootstrap/
│   │   ├── css/bootstrap.min.css
│   │   └── js/bootstrap.bundle.min.js
│   ├── css/
│   │   └── styles.min.css
│   ├── js/
│   │   └── main.js
│   └── img/
```

### 4. Deploy Anywhere
Because the exported files are 100% static HTML, CSS, and JS, deploy them instantly to platforms such as:
- **Cloudflare Pages**
- **GitHub Pages**
- **Netlify**
- **Vercel**
- Any shared hosting or VPS via SFTP
