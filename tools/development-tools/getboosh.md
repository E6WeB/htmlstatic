## Overview

GetBoosh provides a cohesive suite of native desktop applications (for macOS and Windows) built specifically for independent web designers, marketing teams, and static site developers. Designed around a local-first philosophy, all your project files, configurations, design tokens, and audit data reside on your local machine rather than inside a proprietary cloud account.

The GetBoosh ecosystem connects visual web design, CSS token architecture, and search optimization into a unified workflow where apps share a single design system and output production-ready HTML, CSS, and audit reports without recurring SaaS markups or seat limits.

---

## The GetBoosh App Suite

### 1. BooshDESIGN
A visual web design canvas where every control is directly bound to design tokens defined in your `globals.css`. Because the canvas is rendered by a real browser engine, there is no fragile code translation or "export" step—what you design outputs clean, BEM-named semantic HTML and standard CSS directly into your project.

### 2. BooshSEO
A desktop search intelligence and audit suite covering keyword research, technical site audits, rank tracking, competitor analysis, backlink discovery, and AI visibility. BooshSEO runs strictly when you click run—no background cloud crawlers polling on schedules or silently running up bills. Users bring their own DataForSEO API key, paying only wholesale data costs rather than marked-up monthly platform subscriptions.

### 3. FEWD Studio
A desktop visual inspection layer for real HTML, CSS, and JavaScript projects. Click any DOM node on the live canvas to inspect, modify, and refine styling directly on your computer without running heavy web-based devtools.

### 4. Gen CSS
A focused utility that generates the foundational `globals.css` utilized across all projects. From just six primary brand colors, Gen CSS builds a complete, accessible OKLCH color palette and a robust two-layer design token system.

## Key Highlights & Features

1. **Local-First & Data Sovereignty**: All files live on your computer in open formats that open without vendor dependencies. You retain full ownership of your data at all times.
2. **Token-Bound Visual Design**: Impossible to generate invalid or detached CSS—every layout and style rule strictly references tokens from your project's design system.
3. **No Per-Seat Cloud Fees**: One license covers your machine without punitive per-seat tiers or hidden monthly cloud bandwidth surcharges.
4. **Wholesale SEO Costs**: Bring-your-own-key architecture ensures you only pay for search data when running intentional audits.
5. **Seamless Static Workflow**: Outputs pure HTML and modular CSS ready to drop into static site generators like Astro, 11ty, or Hugo.
