## Overview

In this comprehensive video walkthrough, **WP Easy** explores AI-assisted static site generation from the perspective of WordPress and Bricks Builder users. Instead of wrestling with WordPress plugins or converting dynamic databases after the fact, this session demonstrates building a fast, data-driven static website directly from a client brief and mood board using an autonomous AI coding agent.

The video documents an entire real-time session—sped up during wait times with a live clock—taking a raw project from local Git scaffolding all the way to global edge deployment on Cloudflare Workers.

---

## What You'll Learn

1. **Why Static First**: Understanding when data-driven static architectures beat dynamic CMS complexity.
2. **AI Agent Scaffolding**: Supplying the coding agent with repo instructions and local project skills so it acts as an experienced front-end developer.
3. **Mapping Briefs & Design Systems**: How the agent parses non-standard client color names and mood boards into CSS custom properties before writing code.
4. **Data-Driven Templates with JSON & Alpine.js**: Building lightweight, interactive project grids powered by JSON files and filtered seamlessly with [Alpine.js](https://alpinejs.dev/)—no heavy build steps or node_modules compilation required.
5. **Interactive GSAP Effects**: Incorporating smooth scroll and hover animations from the Bricks Productivity library into pure static HTML.
6. **Deploying to Cloudflare**: Instant production deployment to Cloudflare and auditing the result with Google PageSpeed Insights (hitting 100/100 performance).
