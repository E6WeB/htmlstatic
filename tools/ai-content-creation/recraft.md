## Overview

Recraft is an AI design platform built specifically for graphic designers, web developers, and digital creators. Unlike general AI art tools that generate flat bitmap images (JPEG/PNG), Recraft is capable of generating pure, clean vector SVG graphics with infinitely scalable paths and editable layers.

For static website creators, SVG illustrations are the gold standard: they have minuscule file sizes (often just 5–20 KB), load instantly, look crisp on any screen resolution or Retina display, and can be styled dynamically with CSS.

---

## Key Highlights & Features

- **Native Vector SVG Generation**: Generates clean vector paths that can be embedded directly into HTML `<svg>` tags.
- **Brand Consistency**: Define custom color palettes and illustration styles to ensure every graphic matches your website's design system.
- **Multiple Visual Styles**: Generate 2D line art, flat vector art, isometric illustrations, 3D graphics, and custom icon sets.
- **In-Canvas Vector Editing**: Clean up shapes, change color fills, and adjust anchor points directly in your browser.

---

## Example Usage with Static Websites

1. Open Recraft and set your website's exact brand HEX color codes.
2. Select **Vector Art** style and prompt:
   ```text
   "A modern minimalist hero illustration of a fast static website loading on a laptop, clean line art"
   ```
3. Export the graphic as an optimized `.svg` file.
4. Drop the SVG into your static website:
   ```html
   <img src="assets/images/hero.svg" alt="Fast static website loading illustration" width="600" height="400">
   ```
