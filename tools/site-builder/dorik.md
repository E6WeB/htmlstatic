## Overview

Dorik is a no-code website building platform featuring AI site generation, a drag-and-drop visual editor, pre-built UI blocks, and static HTML/CSS/JS export on supported plans.

---

## Key Highlights & Features

1. **AI Website Generation**: Generate page layouts, copy, and imagery from a text prompt.
2. **UI Block Library**: Hundreds of pre-designed sections and templates for SaaS, agencies, and portfolios.
3. **Clean Code Export**: Export static HTML, CSS, and JavaScript files to host anywhere.
4. **Global CDN Hosting**: Built-in SSL, custom domains, and form integrations.
