## Overview

Vvveb is an open-source website builder and CMS powered by VvvebJs, featuring a fast drag-and-drop visual HTML/CSS editor, reusable components, and clean HTML output.

---

## Key Highlights & Features

1. **Visual Drag-and-Drop Editor**: Edit HTML layouts, Bootstrap components, and CSS styles live in the browser.
2. **Open Source**: Freely inspect, customize, and self-host the entire builder.
3. **Live Code Editor**: Switch seamlessly between visual canvas editing and raw HTML/CSS code.
4. **Lightweight & Fast**: Minimal footprint with clean markup output.
