## Overview

Siter.io is an online no-code website builder with a Figma-like freeform canvas, AI layout generation, and HTML export for publishing fast static websites without writing code.

---

## Key Highlights & Features

1. **Freeform Visual Canvas**: Familiar layer-based design workflow with responsive breakpoints.
2. **Figma Import**: Import designs directly from Figma and convert them into live responsive web pages.
3. **HTML Export**: Export clean static HTML and CSS or host directly on custom domains.
4. **AI Builder**: Generate landing page sections and copy quickly from prompts.
