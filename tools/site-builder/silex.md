## Overview

Silex is a free, libre, and open-source visual website builder that runs in the browser and produces clean static HTML and CSS websites, with direct publishing to GitHub Pages, GitLab Pages, Netlify, and FTP.

---

## Key Highlights & Features

1. **100% Free & Open Source**: Libre software with no artificial paywalls or proprietary runtime lock-in.
2. **Visual Drag-and-Drop + Code**: Design visually while retaining access to HTML, CSS, and JS editors.
3. **Static Hosting Integration**: Connect Git repositories or FTP servers to publish static sites directly.
4. **Self-Hostable**: Run Silex locally or on your own server via Docker or Node.js.
