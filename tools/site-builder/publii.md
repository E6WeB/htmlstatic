## Overview

Publii is a free, open-source desktop application for Windows, macOS, and Linux that combines an intuitive WYSIWYG/block editor with static HTML site generation, letting you build and manage sites offline and deploy with one click.

---

## Key Highlights & Features

1. **Offline Desktop Workflow**: Create and preview your entire static website locally with no server required.
2. **One-Click Deployment**: Sync generated static HTML directly to GitHub Pages, GitLab Pages, Netlify, S3, or SFTP.
3. **Built-In SEO & Performance**: Automatic sitemaps, Open Graph metadata, responsive images, and clean HTML output.
4. **Open Source (GPL-3.0)**: Free to use with a marketplace of themes and plugins.
