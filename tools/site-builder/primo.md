## Overview

Primo is an open-source visual site builder and static CMS where developers build reusable blocks with HTML, CSS, JavaScript, or Svelte, and clients edit pages visually before publishing pure static HTML.

---

## Key Highlights & Features

1. **Block-Based Code + Visual Editing**: Write custom HTML/CSS/Svelte blocks while giving editors a clean visual interface.
2. **Pure Static Output**: Compiles sites down to fast static HTML, CSS, and JS files.
3. **Git & GitHub Publishing**: Push built static sites directly to GitHub repositories for deployment on any CDN.
4. **Self-Hostable & Open Source**: Run Primo on your own infrastructure with zero vendor lock-in.
