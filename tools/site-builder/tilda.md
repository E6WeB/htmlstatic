## Overview

Tilda is a visual website builder known for its typography-driven editorial blocks and Zero Block freeform editor, with support for exporting static HTML, CSS, JS, and assets on business plans.

---

## Key Highlights & Features

1. **550+ Pre-Designed Blocks**: Curated responsive blocks for storytelling, landing pages, and portfolios.
2. **Zero Block Editor**: Full manual control over positioning, animations, and responsive breakpoints.
3. **Static Source Export**: Export complete HTML, CSS, JavaScript, and images for self-hosting.
4. **Built-In Forms & SEO**: Integrated form handling, metadata controls, and fast CDN delivery.
