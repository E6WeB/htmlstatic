## Overview

Blocs is a native website builder for macOS, iPad, and iPhone designed to let creators build fast, modern, responsive websites visually without writing code. It exports clean, self-contained HTML, CSS, and JavaScript files ready to deploy on any static host.

---

## Key Highlights & Features

1. **Native Apple Experience**: Built specifically for macOS, iPadOS, and iOS with offline editing.
2. **Clean Static Export**: Generates production-ready HTML, CSS, JS, and assets with zero server dependencies.
3. **Built-in Blocs & Brics**: Modular pre-built sections and extensible components for rapid page assembly.
4. **Universal Hosting**: Export to a folder or publish directly via FTP/SFTP to any static web host or CDN.
