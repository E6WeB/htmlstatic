## Overview

TeleportHQ is a collaborative low-code front-end design and website building platform that lets teams design visually and export clean static HTML, CSS, or modern framework code with one click.

---

## Key Highlights & Features

1. **Clean Code Export**: Download production-ready static HTML/CSS or export to React, Next.js, Vue, and Astro.
2. **Figma Plugin**: Convert Figma components and layouts directly into editable responsive code.
3. **One-Click Static Deploy**: Publish straight to Vercel, Netlify, or GitHub Pages.
4. **Real-Time Collaboration**: Multiplayer visual editing for designers and developers.
