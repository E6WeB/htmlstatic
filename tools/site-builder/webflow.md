## Overview

Webflow is a visual web development platform that translates visual box-model, Flexbox, and CSS Grid controls into clean semantic HTML, CSS, and JavaScript, with static code export available on paid Workspace plans.

---

## Key Highlights & Features

1. **Full CSS Control**: Visual interface for Flexbox, CSS Grid, custom properties, and responsive breakpoints.
2. **Static Code Export**: Export clean, minified HTML, CSS, JS, and assets to host on any static host.
3. **Interactions & Animations**: Build scroll-triggered and hover animations visually without writing JS.
4. **Component System**: Reusable components, design tokens, and class-based styling.
