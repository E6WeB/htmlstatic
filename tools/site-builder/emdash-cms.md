## Overview

EmDash CMS is an open-source, TypeScript-native content management system and site builder built on top of Astro, designed to replace legacy PHP CMS stacks with modern static and edge-first architecture.

---

## Key Highlights & Features

1. **Built on Astro**: Combines Astro's zero-JS-by-default output with structured content management.
2. **Open Source & Type-Safe**: Full TypeScript codebase with modern developer ergonomics.
3. **Edge & Static Ready**: Deploy cleanly to Cloudflare, Netlify, Vercel, or any static/edge host.
4. **Structured Content**: Manage collections, media, and pages without WordPress plugin bloat.
