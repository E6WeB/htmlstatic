## Overview

Mobirise is an offline desktop application for Windows, macOS, and Linux that lets users assemble mobile-friendly websites using pre-designed blocks and export them as pure static HTML files.

---

## Key Highlights & Features

1. **Offline Desktop App**: Build websites locally without vendor lock-in or mandatory cloud accounts.
2. **Block-Based Visual Editor**: Drag and drop hero sections, galleries, pricing tables, and forms.
3. **Static HTML Export**: Publish directly to a local folder, FTP, or GitHub Pages.
4. **Cross-Platform**: Available natively for Windows, macOS, and Linux.
