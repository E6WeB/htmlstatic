## Overview

RapidWeaver (by Realmac Software) is a long-standing native macOS website builder designed to help creators visually build responsive websites and publish clean static HTML, CSS, and assets to any web host.

---

## Key Highlights & Features

1. **Native macOS App**: Smooth, local-first visual editing tailored for Mac users.
2. **Clean Static Publishing**: Exports standard static HTML sites or publishes directly via FTP/SFTP.
3. **Extensible Ecosystem**: Supports themes, add-ons, and custom HTML/CSS/JS code injection.
4. **Zero Database Overhead**: Generates static files that run securely on any CDN or static host.
