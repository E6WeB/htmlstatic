## Overview

Pinegrow Web Editor is a native desktop application (macOS, Windows, Linux) that lets developers and designers build and edit real HTML and CSS files visually—with multi-page editing, CSS Grid/Flexbox tools, and zero proprietary lock-in.

---

## Key Highlights & Features

1. **Works on Real HTML & CSS**: Opens and saves standard local `.html` and `.css` files with no export translation step.
2. **Tailwind & Bootstrap Support**: Built-in visual controls for Tailwind CSS, Bootstrap, and custom CSS stylesheets.
3. **Multi-Page & Component Editing**: Edit multiple responsive viewports side by side and reuse HTML components.
4. **Local-First & Offline**: Runs locally on your machine with full Git and code editor compatibility.
