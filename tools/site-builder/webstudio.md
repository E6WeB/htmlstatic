## Overview

Webstudio is an open-source visual website builder that gives designers and developers full CSS power without vendor lock-in, supporting static HTML/CSS export and deployment to Cloudflare, Vercel, Netlify, or any static host.

---

## Key Highlights & Features

1. **Open Source & Zero Lock-In**: Self-hostable builder with full ownership of your generated site code.
2. **Web Standards First**: Direct mapping to standard CSS properties, tokens, Flexbox, and Grid.
3. **Static & Edge Deployment**: Export static builds or deploy to Cloudflare Pages and other global CDNs.
4. **Headless CMS Friendly**: Connect content from Astro, Markdown, or any REST/GraphQL API.
