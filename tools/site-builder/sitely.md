## Overview

Sitely (formerly Sparkle) is a native visual website builder for macOS and iPadOS that gives designers free-form canvas control and exports optimized, standards-compliant static HTML, CSS, and JavaScript.

---

## Key Highlights & Features

1. **Mac & iPad Native**: Design and publish complete websites directly from macOS or iPadOS.
2. **Optimized Static Output**: Generates clean HTML5, CSS, and responsive images with built-in SEO tools.
3. **Zero Server Dependencies**: Export to a local folder or publish over FTP/SFTP to any static host.
4. **Privacy-Focused**: Built-in GDPR cookie controls and local-first project storage.
