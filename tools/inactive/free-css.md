## How It Works with Static Websites

Download any template `.zip` archive from Free CSS, extract the folder, and customize the markup directly:

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My Static Website</title>
  <link rel="stylesheet" href="assets/css/style.css">
</head>
<body>
  <header class="site-header">
    <h1>Launched with a Static HTML Template</h1>
  </header>
</body>
</html>
```
