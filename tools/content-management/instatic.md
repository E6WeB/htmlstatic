## Overview

Instatic is a free, modern visual site builder developed by the creators of Core Framework. It brings familiar visual web design controls into the static web ecosystem, allowing developers and designers to build high-performance websites without the maintenance overhead, database liabilities, or slow load times of traditional dynamic platforms.

With deep support for modern CSS architectures, design tokens, and AI-assisted generation, Instatic bridges the gap between WordPress page builders and high-efficiency Jamstack deployment.

---

## Key Highlights & Features

1. **100% Free**: Accessible to all creators without artificial page limits or prohibitive subscriptions.
2. **Core Framework Integration**: Built on top of clean CSS architecture, fluid typography, and consistent spacing systems.
3. **AI Generation Options**: Integrated AI assistants help scaffold layouts, generate copy, and propose styling alternatives.
4. **Clean Static Output**: Generates standards-compliant, lightweight HTML, CSS, and JavaScript with optimal Core Web Vitals out of the box.
5. **Familiar Controls for Page Builder Users**: Low barrier to entry for creators coming from WordPress builders like Bricks, Oxygen, or Elementor.

---

## When to Use It

1. Freelancers and agencies wanting a fast, visual way to generate static sites without WordPress overhead.
2. Designers looking for an integrated CSS framework system with visual feedback and AI generation.
3. Anyone wanting a free, visual-first builder that exports pure static code.
