# Tawk.to

> 100% free live chat application to monitor and chat with visitors in real-time.

- **Official Website**: <a href="https://www.tawk.to/" target="_blank" rel="noopener noreferrer">tawk.to</a>
- **Category**: [Live Chat & Support](../README.md#live-chat--support)

---

## Overview

Tawk.to is a completely free live chat and messaging application. Unlike services that charge per-agent fees or restrict basic features, Tawk.to is fully featured for free, supported by optional paid add-ons like hire-an-agent services.

It integrates onto any static HTML page with a single script tag and includes ticketing, knowledge bases, visitor monitoring, and desktop/mobile apps.

---

## Key Highlights & Features

- **100% Free Forever**: No limits on agents, chats, or concurrent conversations.
- **Real-Time Visitor Monitoring**: See which pages visitors are viewing in real time.
- **Built-in Ticketing**: Turn offline inquiries into support tickets automatically.
- **Triggers & Automation**: Send proactive greeting messages based on visitor dwell time.

---

## How It Works with Static Websites

Embed Tawk.to into your static HTML just before the `</body>` tag:

```html
<!--Start of Tawk.to Script-->
<script type="text/javascript">
var Tawk_API=Tawk_API||{}, Tawk_LoadStart=new Date();
(function(){
var s1=document.createElement("script"),s0=document.getElementsByTagName("script")[0];
s1.async=true;
s1.src='https://embed.tawk.to/YOUR_PROPERTY_ID/DEFAULT';
s1.charset='UTF-8';
s1.setAttribute('crossorigin','*');
s0.parentNode.insertBefore(s1,s0);
})();
</script>
<!--End of Tawk.to Script-->
```
