## How to Contribute

This is a community-maintained list. If you know a tool that helps people build or maintain static websites, contributions are welcome! Please see our [Contributing Guide](CONTRIBUTING.md) for full submission guidelines and templates.

You can contribute by:

- Adding a new tool to an existing category.
- Suggesting a new category.
- Correcting an outdated link or description.
- Sharing a free or open-source alternative.
- Updating information about a tool that has changed.

### Option 1: Submit a Pull Request

1. Fork this repository.
2. Edit `README.md`.
3. Add your tool to the most appropriate category.
4. Keep the entry consistent with the existing format.
5. Submit a pull request explaining what the tool does and why it belongs on the list.

### Option 2: Open an Issue

Not comfortable editing Markdown? Open a GitHub issue with the tool name, website URL, category, and a short description. Someone from the community can help add it.

## Submission Guidelines

To keep this resource useful and organized:

- **Relevance**: Tools must be useful for building, hosting, managing, or enhancing static websites or frontend projects.
- **Working links**: Submit the official website whenever possible.
- **Clear descriptions**: Explain what the tool does in one sentence.
- **Honest listings**: Clearly identify free, freemium, paid, and open-source options when known.
- **No spam**: No link schemes, promotional submissions disguised as recommendations, or unrelated services.
- **No duplicates**: Check the existing list before submitting a new entry.
- **No affiliation required**: You can submit a tool you use or one you have discovered, whether or not you are affiliated with its creators.
- **Community first**: Favor useful information over advertising or self-promotion.

> [!NOTE]
> Tools are listed for discovery and convenience, not as endorsements. Please verify pricing, features, and service availability on each provider's website.
