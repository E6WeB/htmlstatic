# Static Website Toolkit

> A community-curated collection of tools, services, and resources for building, hosting, and improving static websites with HTML, CSS, and JavaScript.

<a href="https://creativecommons.org/publicdomain/zero/1.0/" target="_blank" rel="noopener noreferrer"><img src="https://img.shields.io/badge/License-CC0_1.0-blue.svg" alt="License: CC0 1.0"></a>
<a href="CONTRIBUTING.md"><img src="https://img.shields.io/badge/PRs-welcome-brightgreen.svg" alt="PRs Welcome"></a>

You don't need WordPress or a traditional CMS to build a great website. From contact forms and blog comments to hosting, analytics, payments, and newsletters, there are tools that let you add useful features to a static website without managing a full backend.

Know a useful tool or site? **<a href="https://github.com/E6WeB/htmlstatic/issues/new/choose" target="_blank" rel="noopener noreferrer">Submit it via GitHub Issues</a>** to share it with the community!

## How to Contribute

This is a community-maintained list. If you know a tool that helps people build or maintain static websites, contributions are welcome! Please see our [Contributing Guide](CONTRIBUTING.md) for full submission guidelines and templates.

You can contribute by:

- Adding a new tool to an existing category.
- Suggesting a new category.
- Correcting an outdated link or description.
- Sharing a free or open-source alternative.
- Updating information about a tool that has changed.

### Option 1: Submit via GitHub Issues (Recommended)

The easiest way to submit new sites, tools, and links is directly through our GitHub Issues:

1. Go to the **<a href="https://github.com/E6WeB/htmlstatic/issues" target="_blank" rel="noopener noreferrer">GitHub Issues Section</a>** and click **<a href="https://github.com/E6WeB/htmlstatic/issues/new/choose" target="_blank" rel="noopener noreferrer">New Issue</a>**.
2. Use the **Submit a Tool or Site** template.
3. Provide the tool name, official HTTPS website, category, and a one-sentence description.
4. Submit the issue! Once the site is verified, it will be added to `README.md`.

### Option 2: Submit a Pull Request

If you prefer to edit Markdown directly:

1. Fork this repository.
2. Edit `README.md` and add your entry to the most appropriate category table.
3. Keep the entry consistent with the existing format (see [CONTRIBUTING.md](CONTRIBUTING.md)).
4. Submit a pull request explaining what the tool does and why it belongs on the list.

## Submission Guidelines

To keep this resource useful and organized:

- **Relevance**: Tools must be useful for building, hosting, managing, or enhancing static websites or frontend projects.
- **Working links**: Submit the official website whenever possible.
- **Clear descriptions**: Explain what the tool does in one sentence.
- **Honest listings**: Clearly identify free, freemium, paid, and open-source options when known.
- **Zero advertisement & no affiliate links**: Zero advertisement and no affiliate links are allowed. No link schemes, promotional campaigns disguised as recommendations, or affiliate tags.
- **No duplicates**: Check the existing list before submitting a new entry.
- **No affiliation required**: You can submit a tool you use or one you have discovered, whether or not you are affiliated with its creators.
- **Community first**: Favor useful information over advertising or self-promotion.

> [!NOTE]
> Tools are listed for discovery and convenience, not as endorsements. Please verify pricing, features, and service availability on each provider's website.
