## Overview

Bunny Fonts is an open, privacy-friendly font platform designed as a 100% drop-in replacement for Google Fonts. Built by the team at Bunny.net, it collects zero personal data, generates zero tracking cookies, and does not log user IP addresses.

To use it on a static site, you simply replace `fonts.googleapis.com` with `fonts.bunny.net` in your HTML font link.

---

## Key Highlights & Features

- **100% GDPR Compliant**: Zero logs, zero tracking, and no cookie requirements.
- **Exact Google Fonts Drop-In**: Uses identical font families, weights, and query parameters.
- **Global High-Speed CDN**: Fast edge delivery across hundreds of worldwide PoPs.
- **100% Free**: Free to use for both personal and commercial static websites.

---

## How It Works with Static Websites

Switch from Google Fonts to Bunny Fonts with a one-word URL change:

```html
<!-- Original Google Fonts URL:
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Inter:wght@400;600;800&display=swap">
-->

<!-- 100% Privacy-First Bunny Fonts Drop-In: -->
<link rel="preconnect" href="https://fonts.bunny.net">
<link href="https://fonts.bunny.net/css?family=inter:400,600,800&display=swap" rel="stylesheet" />
```

---

## When to Use It

- Any static website serving European visitors that needs strict GDPR compliance.
- Site creators who want beautiful typography without Google tracking their audience.
- Fast, reliable web font hosting without legal risks.
