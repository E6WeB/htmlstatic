# A Blueprint for Beginners on Static HTML Websites

Building your first website does not require paying for a VPS, wrestling with PHP plugins, or setting up a database. A modern **static HTML website** is a folder of `.html`, `.css`, and `.js` files served directly from a global CDN—making it fast, virtually unhackable, and free to host.

This blueprint walks you through the exact pieces you need to go from a blank folder to a live static website, plus how to bookmark your favorite tools on StaticStack using your GitHub account.

---

## 1. Why Start with Static HTML?

Before picking tools, it helps to understand why static HTML is the best starting point for beginners and indie builders:

- **Zero Server Maintenance:** There is no WordPress admin to patch, no database to back up, and no runtime crashes.
- **Instant Page Loads:** Pre-built HTML files are cached at edge locations worldwide, giving you sub-second load times out of the box.
- **Free Forever Tiers:** Major hosts give away generous bandwidth and HTTPS certificates for static sites at \$0/month.

---

## 2. The 4-Piece Beginner Blueprint

Instead of browsing 150+ tools one by one, start with these four proven categories:

### Piece 1: HTML Templates & Clean CSS
You do not have to design every button and grid from scratch. Pick a clean responsive starter template from our **HTML Templates** category, customize the text and colors, and focus on your message.

### Piece 2: Free Edge Hosting
Connect your GitHub repository (or drag-and-drop your folder) to **Cloudflare Pages**, **GitHub Pages**, or **Netlify**. Every time you push an update, your live site rebuilds and deploys automatically with free SSL.

### Piece 3: Contact Forms Without a Backend
Static HTML pages cannot run server-side mail scripts, so point your `<form action="...">` to a static form endpoint like **Web3Forms** or **Formspree**, and pair it with **Cloudflare Turnstile** to block spam bots.

### Piece 4: Lightweight Motion & Search
Need subtle animations or site search? Add **AOS** or **LottieFiles** / **useAnimations** for crisp vector motion, and **Pagefind** for fast client-side search with zero backend servers.

## 3. Save Your Blueprint with My Static Stack (GitHub Login)

As you explore StaticStack, you can save the exact tools from this blueprint into your own personal bookmark list at [**My Static Stack**](/stack/).

### How to Sign In with GitHub
1. Look at the **left navigation rail** on any StaticStack page and click the **Login** icon (right below **Contact & Connect**), or visit [/stack/](/stack/) directly.
2. Authorize with your **GitHub account** via OAuth. Using GitHub keeps spam out and lets your saved stack follow you across devices.
3. That **same GitHub login** also works across the **Community Forum** so you can ask questions, upvote replies, and mark solutions.

### How to Add Tools to Your List
- Click the flat **bookmark icon** (`Save to Stack`) on any tool card, archive row, or tool detail page.
- Open [**My Static Stack**](/stack/) from the left rail (or the **StackBot** quick menu) to view your saved tools in a clean table with **Category**, **Tool**, **Delete**, and **Copy Link** share buttons.
- **Retention Note:** To keep our database lightweight, saved bookmarks are automatically cleared if you haven't logged in for **2 weeks (14 days)**.

---

## 4. Your 10-Minute Launch Checklist

1. **Pick a starter template** and edit `index.html` locally.
2. **Bookmark your chosen hosting and form tools** to [My Static Stack](/stack/) so you don't lose them.
3. **Push your folder to GitHub** and connect it to **Cloudflare Pages** or **GitHub Pages**.
4. **Wire up your contact form** with **Web3Forms** and test a real submission.
5. **Share your finished site** in the [StaticStack Community](/community/)!
