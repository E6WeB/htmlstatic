Giscus

GitHub Discussions-powered comment widget for static blogs and docs.

  • Official Website: giscus.app
  • Category: Comments & Community
  • Type: Open Source Comment Widget

Overview

Giscus is a modern, privacy-respecting comment widget powered by GitHub Discussions. Visitors log in with their GitHub account to leave comments and reactions on your static blog posts or documentation pages.

Because comments are stored in your repository's GitHub Discussions, you have complete ownership of your data with no intrusive tracking, ads, or third-party tracking scripts.

Key Highlights & Features

  • 100% Free & Open Source: No subscriptions, advertisements, or tracking scripts.
  • Data Ownership: All comments are stored directly in your GitHub Discussions.
  • Reactions & Emoji: Native support for GitHub reactions (👍, ❤️, 🚀).
  • Theme Matching: Supports Light, Dark, High-contrast, and custom CSS themes.

How It Works with Static Websites

Include the Giscus script tag on your blog post page:

<div class="giscus"></div>

<script src="https://giscus.app/client.js"
        data-repo="your-username/your-repo"
        data-repo-id="R_kgDO..."
        data-category="Announcements"
        data-category-id="DIC_kwDO..."
        data-mapping="pathname"
        data-strict="0"
        data-reactions-enabled="1"
        data-emit-metadata="0"
        data-input-position="bottom"
        data-theme="preferred_color_scheme"
        data-lang="en"
        crossorigin="anonymous"
        async>
</script>

When to Use It

  • Technical blogs, developer documentation, and open-source websites.
  • Communities where visitors already have GitHub accounts.
  • Site owners who want zero maintenance and full data ownership.
