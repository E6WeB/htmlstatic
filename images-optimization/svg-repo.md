> Browse and download thousands of free SVG icons and vectors for commercial use.

---

## Overview

SVG Repo is an extensive collection of over 500,000 open-licensed SVG vectors, icons, and illustrations. All vectors are free for personal and commercial projects, making it a valuable asset repository for static site designers and developers.

The site includes built-in SVG editing and color customization tools so you can tweak icons before downloading.

---

## Key Highlights & Features

- **500,000+ Vectors**: Monoline, duotone, flat, and glyph styles across every category.
- **Commercial License**: Free for commercial use with clear licensing tags.
- **In-Browser Color Customizer**: Change icon colors and dimensions before downloading.
- **Direct Copy SVG Code**: Copy raw SVG XML markup straight into HTML documents.

---

## How It Works with Static Websites

Use downloaded SVGs directly inline in your HTML for optimal styling control:

```html
<!-- Inline SVG for CSS styling and instant rendering -->
<svg width="24" height="24" viewBox="0 0 24 24" fill="none" stroke="currentColor">
  <path d="M12 2L2 7l10 5 10-5-10-5zM2 17l10 5 10-5M2 12l10 5 10-5" stroke-width="2"/>
</svg>

<!-- Or reference as an image -->
<img src="assets/icons/rocket.svg" alt="Launch Icon" width="24" height="24">
```

---

## When to Use It

- Finding UI icons, navigation buttons, and decorative illustrations for static websites.
- Embedding lightweight scalable vectors that look crisp on high-DPI screens without heavy icon fonts.
