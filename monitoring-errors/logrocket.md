# LogRocket

> Session replay and frontend telemetry to reproduce user-facing issues.

- **Official Website**: <a href="https://logrocket.com/" target="_blank" rel="noopener noreferrer">logrocket.com</a>
- **Category**: [Monitoring & Error Tracking](../README.md#monitoring--error-tracking)
- **Type**: Session Replay & Telemetry

---

## Overview

LogRocket records what users see and do on your website, combining video-like session replay with console logs, network requests, and DOM mutations.

If a visitor experiences a broken form, visual glitch, or failed payment on your static website, LogRocket allows you to watch the exact session playback to diagnose and fix the problem immediately.

---

## Key Highlights & Features

- **Pixel-Perfect Session Replay**: Replays exact user sessions without performance lag.
- **Console & Network Logs**: Captures failed network requests, status codes, and console warnings.
- **Privacy Masking**: Sanitizes sensitive inputs, passwords, and form values automatically.
- **Free Monthly Allowance**: Free tier includes 1,000 recorded sessions per month.

---

## How It Works with Static Websites

Initialize LogRocket in your static HTML:

```html
<!-- LogRocket SDK -->
<script src="https://cdn.lr-in.com/LogRocket.min.js" crossorigin="anonymous"></script>
<script>
  window.LogRocket && window.LogRocket.init('YOUR_APP_ID');
</script>
```

---

## When to Use It

- Debugging checkout errors or form submission bugs on static sites.
- Observing real user behavior, UX bottlenecks, and navigation friction.
- Static web apps with complex client-side states.
